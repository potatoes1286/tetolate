# Third-Party Software

tetolate uses third-party software and models. Each keeps its own license.

Main components include:

- [PaddleOCR and PaddlePaddle](https://github.com/PaddlePaddle/PaddleOCR)
- [PaddleOCR-VL](https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6)
- [llama.cpp](https://github.com/ggml-org/llama.cpp)
- [PyTorch](https://github.com/pytorch/pytorch)
- [LaMa](https://github.com/advimman/lama)
- [ImageMagick](https://imagemagick.org/)
- [OpenCV](https://opencv.org/)
- [Pillow](https://python-pillow.org/)
- [FastAPI](https://fastapi.tiangolo.com/)

Downloaded models and user-provided fonts are not distributed by this repository.
Check their licenses before use or redistribution.
