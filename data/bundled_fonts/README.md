# Bundled fonts

These fonts are open stand-ins for users who do not install professional comic
fonts. Tetolate uses `ComicNeue-Bold.ttf` as its default backup font.

Files in `data/fonts/` take precedence over bundled files with the same name.
A user `data/fonts/font_use.txt` replaces the bundled role mapping.

All bundled fonts use the SIL Open Font License 1.1. The applicable copyright
notice and complete license for each family are in `licenses/`. See `SOURCES.md`
for the pinned upstream revisions and file checksums.
